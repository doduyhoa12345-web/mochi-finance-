# Mochi Finance V0.5.1

Incremental update from V0.5.

- Be Vietnam Pro typography across the app.
- History keeps monthly summaries and now groups transactions by day.
- Each day shows total expense, Actual Expense, income, category chips and transaction count.
- Expand a day to see its full daily summary and individual transactions.
- Click a transaction to reuse the V0.5 edit/delete modal.
- No database/schema changes required.
