# Mochi Finance V0.5
Neon-connected personal finance dashboard.

## V0.5
- Smarter Vietnamese parser: aliases, shorthand amounts, multiple expenses, income/refund/transfer, relative/explicit dates.
- No hard-coded October/date in UI.
- Light youthful UI with pale-blue sidebar and category icons.
- Overview charts for category mix and daily spending.
- Center modal transaction editor.
- Expandable History with transaction detail.
- Inline Budget editing.
- Redesigned asset/credit Account cards.
- Category add/edit/delete in Settings.

## Deploy
Set Vercel Root Directory to `mochi-finance-v0.5` and redeploy. Existing `DATABASE_URL` is reused. No SQL migration is required from V0.4.
